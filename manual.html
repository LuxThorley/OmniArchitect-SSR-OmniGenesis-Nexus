Instruction Manual

This page explains every part of the site in ordinary language. No special training is needed.

What is this website?

What it is: An interactive picture and a set of buttons that let you watch a simple rule-based structure grow. The coloured shells in the background are layers of that structure.

How to use it: Open the main page, press the buttons, and watch the numbers and the background change. You can also type a description and ask for a picture.

Why it exists: To show, in a clear and safe way, an idea from a philosophical essay called Stratified Source Realism. The idea is that a complete world can be understood as the smallest stable result of a set of generative rules. This site only demonstrates the mathematics; it does not claim to describe the real universe.

The background picture

What it is: Nested glowing shells (like wireframe spheres) and floating dots. Each shell is one layer of the model.

How it works: As you press “Add one layer” or “Grow until stable”, the active layer lights up in gold and the centre glows more brightly when the structure settles.

Why it is there: To give a visual sense of the layered, hierarchical idea without requiring any equations.

Build the Structure panel

What it is: Controls that apply the model’s rules step by step.

How to use the buttons:

  • Add one layer — Applies the rules once and adds any new pieces that fit.
  • Grow until stable — Keeps applying the rules until almost nothing new appears.
  • Start over — Clears the model and returns to the starting set of pieces.
  • Save a record — Downloads a small file that lists what was built.

The numbers:

  • Pieces in the model — How many distinct items the rules have accepted so far.
  • How settled it is — A number that gets smaller as fewer new pieces appear. Close to zero means the structure has stabilised.
  • Coherence — A simple percentage that rises as the model settles. It is only a visual guide.

The layer list: Eight simple stages from basic blocks up to an overview. The highlighted layer is the one the model is currently emphasising.

Why these rules: They illustrate a well-known mathematical result (the Knaster–Tarski fixed-point theorem). Under certain conditions a process of adding pieces that obey constraints will reach a smallest stable collection. The site shows one toy version of that idea.

Image Maker

What it is: A box where you type a description and receive a picture.

How to use it: Type anything you like (for example “a glowing crystal lattice at sunset”). Press “Make an image” for one picture, or “Make four related pictures” for a short sequence.

What happens behind the scenes: The site first checks the text for a short list of disallowed topics (violence, weapons, etc.). If the text passes, it is sent to a free public image service that draws a picture. The service is outside this website; if it is busy the page simply shows a short message.

Why the check: To keep the public demonstration safe and consistent with a simple non-harm principle.

Live Status

What it is: A small panel that ticks every few seconds and records short notes.

How to read it: The heartbeat count rises regularly. The balance score is a fixed symbolic number. The stream line shows whether an optional live feed is reachable; if not, the page continues with its own timer.

Why it is there: To give a gentle sense that the demonstration is “alive” and to log events you can scroll through.

Activity Log

What it is: A short scrolling list of plain messages (“Add one layer”, “Image ready”, etc.).

How to use it: Just watch it. You can scroll inside the box on a phone.

Technical and philosophical notes (optional)

The underlying idea comes from an essay called Stratified Source Realism. In that essay the whole of reality is proposed to be the smallest collection of structures that is closed under a set of generative rules and constraints. Mathematicians call such a collection a least fixed point. This website implements a tiny, completely safe version of the same idea so that anyone can press buttons and see the process. Nothing on the site claims to be a scientific discovery or a description of the physical world.

If you want the full formal statement, the original essay and related documents are available separately. This manual is deliberately limited to what is needed to use and understand the public demonstration.
